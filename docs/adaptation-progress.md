# 差异补齐进度

2026-10-08，当前默认配置：厂长、干饭、一碗、蔬菜、动漫巴士。

这些是独立站点，不与已有 Cat 仓库合并，也不会自动导入 Android 订阅。上传本项目后使用生成的 `.js.md5` 新建仓库即可。

本轮实现了两个缺失条目：

- 蔬菜：复用 AppGet 协议，新增文本发布页的动态接口发现，避免把临时 IP 固化在配置中；首页没有推荐时读取首个分类。
- 动漫巴士：独立 HTML 适配器，包含分类分页、搜索、集数列表、iframe 参数读取、播放器 `/api/parse` 请求和 `hls_rewrite` 地址处理。不执行播放器网页里的混淆脚本。

后续尚需协议适配的重点：农民、光盘、潮流、行动/再来、奥特、比特、糯米等。网盘聚合及搜索站还需分享解析与个人账号接口；P2P/磁力站还需播放引擎，不能仅补站名。

已测试但上游不可用的条目和实际播放验证边界见 [验证记录](verification.md)。本轮不声称把三个 Android 订阅的全部站点补齐。
